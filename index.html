Khula

Android app, in testing

A mental wellness app for reflective journaling and emotional support. It has a daily check-in, a private journal with pattern tracking, grounding and breathing tools and an AI companion. If the primary Gemini model times out, a fallback model keeps the app responding. Private journal text is turned into embeddings for retrieval. Crisis resources and a clear notice that it is not a clinical tool are built in.

Android, Gemini API, embeddings and retrieval, provider fallback

An AI email triage prototype. The model classifies a message, looks up earlier messages from the same sender when it needs context, then picks a structured action: flag, draft a reply or archive. It runs on mock email data, and any drafted reply would need a person's approval before sending.

React, Node.js, Express, TypeScript, Gemini API
